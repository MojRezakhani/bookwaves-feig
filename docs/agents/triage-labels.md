# Triage Labels

This repository uses the default canonical triage vocabulary.

## Labels

| Canonical role | Label |
| --- | --- |
| Needs evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for autonomous implementation | `ready-for-agent` |
| Requires human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

## Agent behavior

Skills that triage or manage issues should use these exact strings when representing issue state.
